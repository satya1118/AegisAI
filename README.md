# AegisAI — Vendor Due Diligence & Risk Intelligence Platform

AegisAI is an enterprise analytics project that simulates how organizations evaluate vendor risk, compliance exposure, and financial impact using data analytics and business intelligence dashboards.

---

## Problem

Large enterprises work with hundreds of vendors including logistics providers, cloud platforms, SaaS vendors, and security partners. Vendor monitoring is often manual, fragmented, and reactive.

Organizations need a way to:

• identify high-risk vendors  
• monitor SLA performance  
• quantify financial exposure  
• support procurement decision-making

---

## Solution

AegisAI demonstrates an end-to-end analytics workflow for vendor risk intelligence.

The system:

• Generates simulated vendor performance data using Python  
• Stores vendor data in a PostgreSQL database  
• Uses SQL queries to analyze vendor risk and contract exposure  
• Visualizes insights using a Power BI executive dashboard  

---

## Dataset

The simulated dataset contains **500 enterprise vendors** with attributes such as:

- Contract value
- Vendor category
- SLA breaches
- Incident history
- Compliance flags
- Financial risk indicators
- Service uptime metrics

---

## Key Insights

Analysis revealed:

• **3.8% of vendors were classified as high risk**  
• These vendors represented **4.16% of total contract revenue exposure**  
• SLA breaches were most concentrated in logistics and SaaS vendors  

These insights help procurement teams prioritize vendor review and risk mitigation.

---

## Dashboard

The Power BI dashboard provides executives with:

• Vendor risk distribution  
• Revenue exposure by risk tier  
• SLA breach analysis by vendor category  
• High-risk vendor watchlist
